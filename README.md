# jfournier.net

Personal one-pager for Justin Fournier — Customer Solutions Engineer (enterprise SaaS).

- Single self-contained `index.html` — no build step, no dependencies beyond Google Fonts.
- Dark, minimal design. Blue accent.
- Deployed via Cloudflare Pages (Direct Upload). Custom domain: jfournier.net.

## Deploy

Push to `main` and Cloudflare Pages picks it up (or drag-and-drop `index.html` into Pages → Upload assets).
