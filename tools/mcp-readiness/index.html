Readiness
Six criteria, weighted.

Named use cases carry the most weight. An agent with no question to answer is a demo, not a pilot.

Use cases defined WEIGHT ×3

You have 2-3 named use cases where an agent would save real time — not "AI everywhere."

Data access WEIGHT ×2

The agent can reach the data it needs: sessions, events, CRM, tickets — not screenshots and exports.

MCP / API surface WEIGHT ×2

Your tools expose an MCP server or API the agent can call, available on your plan and enabled.

Governance WEIGHT ×2

Access is scoped: read-only where it should be, secrets handled, audit trail on.

Internal champion WEIGHT ×2

Someone inside owns the pilot and can say yes to the next step.

Success criteria WEIGHT ×2

You know what "worked" looks like: a metric, a baseline, and a decision date.

Red flags
