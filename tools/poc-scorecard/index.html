Score an evaluation before you run it. If it doesn't clear the bar, don't start. Fix the gaps, or walk away. A PoC without success criteria is a science project.

The evaluation
Six criteria, weighted.

Success criteria carries the most weight. Everything else is table stakes — without it, there is nothing to evaluate against.

Problem clarity WEIGHT ×2

The business problem is defined in the buyer's words, not ours.

Success criteria WEIGHT ×3

Success criteria are defined, measurable, and agreed in writing.

Buyer data access WEIGHT ×2

We can run the evaluation against the buyer's real data, not a sample.

Technical fit WEIGHT ×2

It works in their environment: integrations, security, scale.

Economic buyer WEIGHT ×2

The economic buyer is engaged, not just an evaluator.

Exit criteria WEIGHT ×2

There's a decision, a date, and an owner at the end.

Red flags
Any one of these ends it.
